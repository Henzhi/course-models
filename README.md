# 课程教学模型 · 初中生物

按人教版教材分册组织的互动教学模型。全部是**单文件 HTML**——拷到没有网络的教室，双击就能开。

---

## 怎么用

**双击 `index.html`**，按册找到要讲的课，点卡片进入。

- 推荐 Chrome / Edge，窗口宽度 1100 以上（投影仪一般都没问题）
- 上课时按 <kbd>F</kbd> 或点右上角「全屏」，按 <kbd>Esc</kbd> 退出
- 每个模型页左上角有「← 全部模型」，随时换课

**模型页通用快捷键**

| 键 | 作用 |
|---|---|
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> | 切换显示模式 |
| <kbd>←</kbd> <kbd>→</kbd> | 上一步 / 下一步（流程类页面） |
| <kbd>空格</kbd> | 播放 / 暂停（有动画的页面） |
| <kbd>L</kbd> | 隐藏 / 显示标注（先让学生自己认，再揭晓） |
| <kbd>F</kbd> | 全屏 |
| <kbd>Esc</kbd> | 取消选中 |

> 翻页笔一般只有「上/下/回车」，这几个键都能用：**上/下方向键切步骤，回车（空格）播放暂停**。不需要鼠标也能上完整节课。

## 这一页怎么讲：单细胞生物（草履虫）

**① 导入（2 分钟）**
先问：**「一个细胞，能不能自己活着？」**
多数学生会说不能——细胞是身体的一部分，得靠别的细胞配合。
再揭晓：草履虫就是**一个细胞**，它一个人完成了全部生命活动。

**② 怎么动、怎么吃（5 分钟）**
点「**怎么动·怎么吃**」。这条线是三件事：
**纤毛摆动 → 水流把食物带到口沟 → 口沟把食物送进去，形成食物泡。**
强调：纤毛只管运动，口沟只管「进」，食物泡负责消化。

**③ 怎么排泄、怎么呼吸（5 分钟）**
点「**排泄·呼吸**」。这里有本节最容易混的一处：
- **伸缩泡**排的是多余的水和代谢废物
- **胞肛**排的是消化完的食物残渣
- **表膜**负责气体交换（草履虫没有专门的呼吸器官）

**④ 控制中心（3 分钟）**
点「**控制中心**」。草履虫有**大小两个核**：大核管代谢，小核管生殖。
补一句：它是真核生物（有细胞核），但整个身体只有一个细胞——这两句话不矛盾。

**收口（1 分钟）**
一个细胞，七项生命活动全包了。这就是「单细胞生物」的含义。

## 这一页怎么讲：细菌、真菌、病毒

**① 先扫一眼（2 分钟）**
三栏并排：细菌、真菌、病毒。都是肉眼看不见的生物，但**结构差别很大**。

**② 点第一组：细胞壁和细胞膜（3 分钟）**
细菌和真菌都有细胞壁、细胞膜、细胞质。**病毒什么都没有。**

**③ 点第二组：细胞核的有无（5 分钟）——本页最值钱的一屏**
这是区分细菌和真菌的**第一依据**：
- 细菌：DNA 集中在细胞里一个区域，**外面没有核膜**——叫「拟核」，不算成形的细胞核
- 真菌：DNA 在**成形的细胞核**里

一句话钉死：**细菌无核，真菌有核。**

**④ 点第三组：病毒（4 分钟）**
病毒只剩两样：**蛋白质外壳 + 遗传物质**。
追问：**「病毒能自己繁殖吗？」** 不能——必须寄生在活细胞里。

**收口（1 分钟）**
三句话：细菌没有成形的细胞核；真菌有细胞核；病毒没有细胞结构。

**分层建议**
- 基础班：只走 ②③，记住「细菌无核、真菌有核」
- 较好的班：补「荚膜和鞭毛不是所有细菌都有」「酵母菌是出芽生殖」

## 这一页怎么讲：动物体与植物体的结构层次

**① 从细胞往上走（3 分钟）**
停在**第 1 层「细胞」**，问一句：**「一个细胞能构成一只手吗？」**
不能。那要多少？怎么组织起来？这就是这一节要回答的问题。

**② 组织（3 分钟）**
点**第 2 层**。重点讲定义里的三个词：**形态相似、结构相同、功能相同**。
补一句：血液是**组织**，不是器官。

**③ 器官（4 分钟）**
点**第 3 层**。胃从外到内是浆膜、肌肉层、黏膜——**一个器官由多种组织构成**。
追问：**「胃是一种组织，还是多种组织？」** 这一问就把「器官」和「组织」分开了。

**④ 系统（3 分钟）**
点**第 4 层**。胃、小肠、大肠不是各干各的，它们**按顺序配合**完成消化吸收。

**⑤ 切到植物（5 分钟）—— 本页最值钱的一屏**
点右上角「**植物体**」，再一路点到第 3 层「器官」。
然后指着链条的**第 4 格**问：**「这一格为什么是空的？」**
答案就是：**植物没有系统这一层，器官直接构成植物体。**
这一格空着，比讲十遍「植物没有系统」都管用。

**收口（1 分钟）**
两条链并排念一遍：
- 动物：细胞 → 组织 → 器官 → **系统** → 个体
- 植物：细胞 → 组织 → 器官 → 植物体

**分层建议**
- 基础班：只走 ①③⑤，记住「植物没有系统」
- 较好的班：补 ② 的「血液是组织」和「叶是器官」，这两条是一组考点

**快捷键**：1~5 切层级 · A 动物 · P 植物 · ←→ 上下级 · F 全屏

## 这一页怎么讲：细胞通过分裂产生新细胞

**① 导入（2 分钟）**
停在**阶段 1**，只问一句：**「这个细胞分裂成两个，两个新细胞里各有几条染色体？」**
多数学生会猜「一半」。**先不揭晓**，往下走。

**② 复制（3 分钟）**
走到**阶段 2**。重点讲一句：复制出来的那条和原来**一模一样**，两条由**同一个着丝粒**连住。
追问：**「现在有几条染色体？」**——还是 2 条。可以让统计卡片自己说话。

**③ 排列到中央（5 分钟）——本页最值钱的一屏**
切到**阶段 3**。画面变成一列 X，学生第一反应是「4 条」。
**先让学生数棍子**（会数出 4 根），**再让他们数着丝粒**（2 个）。
一句话钉死：**1 个着丝粒 = 1 条染色体**。
这里可以点右上角「显示着丝粒编号」，把编号打在图上，一个一个点着数。

**④ 分离（4 分钟）**
切到**阶段 4**。提醒学生盯住：**断开的是着丝粒，分开的是两条姐妹染色单体**。
注意统计会从 2 跳到 4——这是对的：**每条单体都成了独立的染色体**，但它们马上要被分到两边。
补一句：**「所以这一刻是 4 条，分完每边还是 2 条。」**

**⑤ 形成两个新细胞（2 分钟）**
切到**阶段 5**，回到开头那个问题——**每个新细胞还是 2 条**，和原细胞一模一样。
收口：**新细胞和原细胞相同，所以生物能长大、能修复。**

**分层建议**
- 基础班：全程用 **2 条**，只走 ①③⑤
- 较好的班：切到 **4 条**再走一遍阶段 3，检验学生是不是真会数了（4 条时着丝粒仍是 4 个，不是 8 个）

**快捷键**：空格播放暂停 · ←→ 切阶段 · N 换条数 · L 编号 · R 重置

## 这一页怎么讲：细胞的生活

**① 物质进出（5 分钟）**
先播放粒子，只问一句：**「这么多东西在细胞外面转，哪些能进去？」**
学生会看到：蓝色（氧气）、橙色（葡萄糖）、浅蓝（水）能穿膜，**红色的有害物质一直弹回来**。
暂停一下，指着那颗红色粒子问：「它为什么进不去？」——答案就是细胞膜的选择透过性。

**② 能量转换（5 分钟）**
切到「② 能量转换」，先讲左边的叶绿体：**光能 → 化学能，存进有机物**。
再讲右边的线粒体：**化学能 → 可用的能量，释放出来**。
一句话记住：**叶绿体存钱，线粒体花钱。**
追问一句：**「动物细胞有叶绿体吗？」**——没有，所以动物不能自己制造有机物。

**③ 细胞核控制（5 分钟）**
切到「③ 细胞核控制」，按四个步骤走。每一步只讲一句，不要展开。
最后停在多莉身上问：**「多莉有三个妈妈，它像谁？」**
学生会发现它像 B——**因为细胞核是 B 给的**。遗传信息在细胞核里。

**收口（1 分钟）**
三句话：细胞膜控制物质进出；叶绿体存、线粒体花；细胞核里有遗传物质。

**分层建议**
- 基础班：只走 ①③，② 看一眼「存钱 / 花钱」即可
- 较好的班：补「为什么高倍镜下看不到线粒体」（太小，需要染色）

## 这一页怎么讲：显微镜的使用

**① 认结构（3 分钟）**
点左边显微镜上的部件，让学生说出名字和作用。重点讲一句：**镜筒里是一条竖直的光路**——
所以目镜、镜筒、物镜、通光孔、反光镜必须在同一条线上，差一个都看不到东西。

**② 对光（3 分钟）**
先合上灯、把视野弄暗，问：**「为什么看不见？」**
等学生答出「没有光」，再切到「② 对光」：转低倍物镜 → 对准通光孔 → 调光圈、反光镜。
让学生自己把小光圈换成大光圈、把平面镜换成凹面镜，看视野变亮。

**③ 调焦（3 分钟）**
重点不是记住两个螺旋，而是**顺序**：先降后升。
追问一句：**为什么下降镜筒时眼睛要看物镜？**（怕压碎玻片）——这一问比讲三遍都管用。

**④ 换倍数（4 分钟）——本页最值钱的一屏**
先让学生猜：**「换成 40× 物镜，视野里会变成什么样？」**
多数会说「细胞变大」就完了。再点 40×，三件事同时发生：
**细胞变大、看到的细胞变少、视野变暗**。
然后回到公式：10 × 40 = 400 倍，**不是 50 倍**。

**⑤ 物像移动（4 分钟）**
最反直觉的一步。先不解释，让学生自己拖滑块，观察细胞往哪跑。
再总结：**物像偏哪边，就把玻片往哪边推**——因为像是倒的，移动方向相反。

**收口（1 分钟）**
三句话：放大倍数 = 目镜 × 物镜；物像和玻片反向移动；先低倍、后高倍。

**分层建议**
- 基础班：只走 ①②③⑤，④ 看一眼「细胞变大变少」即可
- 较好的班：补 ④ 的「为什么变暗」，以及「换高倍后只能用细准焦螺旋」

## 这一页怎么讲：植物细胞 vs 动物细胞

**① 导入（2 分钟）**
先不点任何结构，只问一句：**「植物和动物都是细胞构成的，那两种细胞长得一样吗？」**
让学生先猜。多数会说「不一样」，但说不清哪不一样——这就是这节课要解决的。

**② 找共同点（4 分钟）**
点上方「**共同结构**」。画面只亮起四样：细胞膜、细胞质、细胞核、线粒体。
一句话收口：**「不管是草还是人，细胞的基本配置是一样的。」**

**③ 找不同点（5 分钟）**
点「**不同结构**」。植物细胞亮起三样：细胞壁、液泡、叶绿体。
- 点**细胞壁**：「这是墙，不是膜。它在细胞膜外面，起支撑作用——所以树干是硬的。」
- 点**液泡**：「里面装的是细胞液，西瓜甜、花瓣红，都靠它。」
- 点**叶绿体**：这是本节课最容易错的一处。

**④ 突破难点：叶绿体（3 分钟）**
先问：**「洋葱鳞片叶内表皮细胞，有没有叶绿体？」**
学生几乎都会说「有，因为它是植物」。
然后点开叶绿体，看那句易错点：**只有植物体的绿色部分才有叶绿体。洋葱内表皮是无色透明的，所以没有。**
再补一刀：萝卜的根细胞也没有。**「是植物」≠「有叶绿体」，必须是绿色部分。**

**⑤ 收口（1 分钟）**
口诀：**一壁、一泡、一绿体。**
再回扣导入的问题——两种细胞一样吗？**「基本配置一样，植物多三样。」**

**分层建议**
- 基础班：只走 ②③⑤，记住口诀即可
- 较好的班：补 ④ 的追问，再加一句「液泡大小和细胞成熟程度有关」「心肌细胞线粒体特别多，因为它跳个不停」

## 这一页怎么讲：基因在亲子代间的传递

**① 东西放在哪（4 分钟）**
第 1 步。先只问一件事：**基因在哪里？**——不在细胞质里飘，**坐在染色体上**。
数一数：体细胞里有 4 根染色体（简化示意），为什么要两两配对？
一句话：**染色体成对 → 基因也成对，一条来自父方、一条来自母方。**

**② 减半（5 分钟）—— 本页的地基**
第 2 步。形成精子、卵细胞时，**每一对只挑一条进去**。4 根变 2 根。
追问一句：**如果这一步不减半，会发生什么？**——受精后翻倍，一代比一代多。
（学生最常答不出的就是这个"为什么必须减半"。）

**③ 恢复成对（5 分钟）**
第 3 步。精子 + 卵细胞 → 受精卵，两半合起来，又成对了。
**这里是全页最容易算错的地方**：受精卵是 23 + 23 = 46 条，**不是 46 + 46 = 92 条**。
看颜色：受精卵里每一对同源染色体，必然一蓝一红。

**④ 传的是基因（3 分钟）**
第 4 步。整条路走一遍，指住精子和卵细胞：**它们就是桥**。
钉一句判断题：**父母传给子女的是基因，不是性状。** 性状是基因在孩子身上重新表达出来的。

**⑤ 数字链（3 分钟）**
第 5 步。表格两行：46 → 23 → 46，成对 → 成单 → 成对。
一句话收口：**成对、减半、恢复成对**——记住这条链，数字忘了也能推回来。

**收口（1 分钟）**
染色体在哪、怎么减半、怎么恢复。三步走完，后面的显隐性才讲得下去。

**分层建议**
- 基础班：只走 ②③⑤，把「46 → 23 → 46」钉死
- 较好的班：补 ④ 的「传基因不传性状」，以及"如果减半失败会怎样"

## 这一页怎么讲：基因的显性与隐性

**① 矮茎怎么不见了（4 分钟）**
第 1 步。纯种高茎 × 纯种矮茎 → **子一代全是高茎**。
先别解释，只问：**矮茎的性状消失了吗？**
学生多半答"消失了"——那就顺势追问：**既然消失了，它还可能再出现吗？**

**② 它又回来了（5 分钟）—— 本页的地基**
第 2 步。子一代自交，子二代里矮茎又冒出来，**高 : 矮 ≈ 3 : 1**。
这一步的杀伤力在于：**上一问猜"消失"的学生，在这里会自己推翻自己。**
结论一句话：**隐性基因没消失，只是被显性基因盖住了表现。**

**③ 大写显性、小写隐性（4 分钟）**
第 3 步。D 显性、d 隐性。
给三行对照：**DD → 高茎 ｜ Dd → 高茎 ｜ dd → 矮茎**。
强调：**只要有一个 D 就是高茎**，两个都是 d 才矮。

**④ 四种组合（6 分钟）—— 本页最值钱的一屏**
第 4 步。Dd 产生 D、d 两种生殖细胞，两个 Dd 结合就是 2 × 2 = 4 种组合。
表格摆开：**DD、Dd、Dd、dd**。
让学生自己数：**几个高、几个矮？**——3 高 1 矮。

**⑤ 两个比例不能混（4 分钟）**
第 5 步。**基因组成 1 : 2 : 1，性状表现 3 : 1。**
追问：**为什么同一个杂交，两个比不一样？**——因为 DD 和 Dd 长出来都是高茎。
最后一句话钉住：**题目问「高茎有几个」和问「Dd 有几个」，答案不是同一个比。**

**收口（1 分钟）**
显性盖住表现、盖不住传递 → 所以子二代能"重现"矮茎 → 比例是 3 : 1。

**分层建议**
- 基础班：只走 ①②，把「矮茎基因没消失」这一句讲透就够了
- 较好的班：补 ④⑤ 的两个比例，这是遗传题失分最多的地方

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–5 跳步 · L 标注 · F 全屏

## 这一页怎么讲：人的性别决定

**① 第 23 对不一样（4 分钟）**
第 1 步。先给数字：**23 对里前 22 对男女完全一样，只有第 23 对不一样。**
看两条棒的长短：**XX 是两条等长，XY 是一长一短**。
钉一句：**长的是 X，短的是 Y**——不用背别的。

**② 母亲这一侧没有变量（5 分钟）—— 本页的关键**
第 2、3 步连着看。
母亲是 XX → 卵细胞**只能含 X**，只有一种。
父亲是 XY → 精子**含 X 或含 Y**，两种各半。
追问：**「生男生女由母亲决定」这句话错在哪？**——错在母亲根本没得选。

**③ 两种结果（5 分钟）**
第 4 步：X 精子 + 卵 → XX，两条一样长，女孩。
第 5 步：Y 精子 + 卵 → XY，一长一短，男孩。
关键提问：**这条 Y 可能来自母亲吗？**——不可能，所以**性别由父亲给的是 X 还是 Y 决定**。

**④ 各占一半（3 分钟）**
第 6 步。表格两行：两种精子机会各 1/2。
再追一句高频错：**「第一胎是女孩，第二胎是不是更容易生男孩？」**——不会。每一次都是重新掷一次。

**收口（1 分钟）**
母亲只给 X，父亲给 X 或 Y，给 X 是女孩、给 Y 是男孩，机会各半。

**分层建议**
- 基础班：只走 ①②③，把「母亲只给 X」这一句钉死
- 较好的班：补 ④ 的独立事件，以及"为什么自然出生性别比接近 1:1"

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–6 跳步 · L 标注 · F 全屏

## 这一页怎么讲：眼球成像与近视矫正

**① 眼球结构（4 分钟）**
第 1 步。**角膜让光进来、晶状体调焦、视网膜成像、视神经送信号**。
钉一句最容易错的：**「看见」发生在大脑皮层，不在眼睛**。

**② 正常眼（4 分钟）**
第 2 步。两条光线在晶状体处偏折，**会聚点正好落在视网膜上**。
给一个前提：晶状体曲度**可以调节**，所以远近都能看清。

**③ 近视（5 分钟）—— 本页的核心**
第 3 步。会聚点从视网膜上**前移**了，落在视网膜前面，看远处就模糊。
原因两条：**晶状体曲度过大**，或**眼球前后径过长**。
强调方向：**近视是「前面」，不是「后面」。**

**④ 矫正（5 分钟）**
第 4 步。加一片**凹透镜**，它对光有**发散**作用，把会聚点**后移**回视网膜。
一句话钉死：**近视配凹透镜，远视配凸透镜**——凹发散、凸会聚，方向相反。

**⑤ 一张表（2 分钟）**
三行：会聚点、晶状体、矫正镜片。让学生对着表复述一遍。

**收口（1 分钟）**
会聚点在哪，决定看得清不清；镜片的凹凸，决定把会聚点往哪推。

**分层建议**
- 基础班：只走 ③④，记住「近视在前、戴凹透镜」
- 较好的班：补 ① 的「看见在大脑」，以及远视的对应关系

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–4 跳步 · L 标注 · F 全屏

## 这一页怎么讲：传染病及其预防

**① 三个环节（4 分钟）**
第 1 步。**传染源 → 传播途径 → 易感人群**，三个同时具备才流行。
一句话立住本节的骨架：**缺一个就传不下去，所以预防只要打断任意一环。**

**② 传播途径不止一条（3 分钟）**
第 2 步。空气（飞沫）、接触、饮食——三条路都通向同一群人。
问一句：**「流感和痢疾各走哪条路？」** 前者空气、后者饮食。

**③ 三项措施（每步 4 分钟）—— 本页的核心**
第 3/4/5 步依次在链条的三处「下刀」：

| 步骤 | 措施 | 落在哪 | 典型做法 |
|---|---|---|---|
| 第 3 步 | 控制传染源 | 链条起点 | 隔离、治疗病人 |
| 第 4 步 | 切断传播途径 | 链条中间 | 消毒、戴口罩、洗手 |
| 第 5 步 | 保护易感人群 | 链条终点 | 接种疫苗、锻炼 |

每步都让学生看**那一刀落在哪里**——位置对了，名称就不会答错。

**两处必错，逐个拆**
1. **「隔离病人」是控制传染源**，不是切断传播途径。
2. **「接种疫苗」是保护易感人群**——疫苗打在健康人身上，不是控制传染源。

**收口（1 分钟）**
回看表格：环节、措施、举例三列一一对上，顺序不能错位。

**分层建议**
- 基础班：只走 ①③⑤，把「隔离=控源、疫苗=护人」钉死
- 较好的班：补 ② 的多条途径，以及「为什么隐性感染者也属于传染源」

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–5 跳步 · L 标注 · F 全屏

## 这一页怎么讲：免疫三道防线

**① 三道防线（4 分钟）**
第 1 步。**皮肤黏膜 → 杀菌物质和吞噬细胞 → 免疫器官和免疫细胞**。
先给结论：**前两道生来就有、不挑对象；第三道后天获得、只认一种。**

**② 第一道（4 分钟）**
第 2 步。皮肤**挡**、黏膜**粘**、纤毛**扫**。
指墙上那个缺口：**皮肤破损时这道防线就被突破了**——所以伤口要处理。

**③ 第二道（4 分钟）**
第 3 步。**溶菌酶**溶解细菌的细胞壁，**吞噬细胞**伸出伪足把病原体吞进去。
这里要钉一句：**吞噬细胞属于第二道，不是第三道。**

**④ 第三道（6 分钟）—— 本页最值钱的一屏**
第 4 步。淋巴细胞产生**抗体**，抗体像「Y 形的夹子」专门夹住这种病原体。
关键：**抗体有专一性**——得过麻疹不会再得，但明年照样会得流感。

**⑤ 一张表 + 疫苗（4 分钟）**
第 5 步。三行：生来就有？针对谁？免疫类型？
最后追问：**「疫苗是抗原还是抗体？」**——是抗原。接种是把灭活/减毒的病原体送进去，让身体自己产生抗体。

**收口（1 分钟）**
前两道挡住大部分，漏网的靠第三道精准清除。

**分层建议**
- 基础班：只走 ①④，记住「三道防线」和「抗体有专一性」
- 较好的班：补 ③ 的「吞噬细胞属于第二道」，这是最常错的一处

## 这一页怎么讲：反射弧

**① 五个环节（4 分钟）**
第 1 步。一条单向的路：**感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器。**
先只强调方向，不讲细节。缺一段，反射就不成立。

**② 起点：感受器在皮肤（3 分钟）**
第 2 步。手指碰到烫的东西，**皮肤里的神经末梢**把「烫」变成**神经冲动**。
提醒一句：感受器不是「手」，是皮肤里极细的末梢。

**③ 中枢在脊髓（4 分钟）**
第 3 步。冲动沿传入神经进脊髓灰质，在**突触**处换一个神经元。
这里埋一个伏笔：**缩手反射不需要大脑**。

**④ 传出与效应器（4 分钟）—— 本页最容易错的一屏**
第 4 步。传出神经把指令送到**效应器**——肌肉收缩，手缩回。
钉两句：**传入进、传出出**（方向别反）；**效应器 = 神经末梢 + 肌肉**（少了肌肉就不算）。

**⑤ 为什么先缩手后觉疼（5 分钟）—— 本页最值钱的一屏**
第 5 步。先问：**「手已经缩回来了，为什么过一会儿才觉得疼？」**
因为缩手这条路只到脊髓就返回（短），而「疼」要上行到**大脑皮层**才能形成痛觉（长）。
两个结论：① 缩手反射不需要大脑；② 痛觉在大脑皮层形成，不在手上、也不在脊髓里。

**收口（1 分钟）**
感受器收、传入送进去、中枢处理、传出送出来、效应器做动作。

**分层建议**
- 基础班：只走 ①④，记住「传入进、传出出」
- 较好的班：补 ⑤ 的两条路径对比，这是每年必考的推理题

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–5 跳步 · L 标注 · F 全屏

## 这一页怎么讲：关节与肌肉的配合

**① 先看两栏（3 分钟）**
不点任何结构，只问：**「屈肘的时候，上臂这两块肌肉在干什么？」**
多数学生会说「都在用力」。先不揭晓。

**② 对比粗细（4 分钟）**
点「骨骼与肌肉」。左右两栏是同一只手臂的两个姿态，**粗的是收缩，细的是舒张**。
一句话钉死：**屈肘时肱二头肌收缩、肱三头肌舒张；伸肘时反过来。**

**③ 为什么必须两组（4 分钟）—— 本页的核心**
追问：**「肌肉能不能把骨头推开？」**——不能，肌肉只会**拉**。
所以每个动作都要有对抗的一组：一组收缩把骨头拉过去，另一组舒张让开。

**④ 关节结构（5 分钟）**
点「关节结构」。五个部件两组功能：
- **灵活**：关节软骨 + 关节腔里的滑液
- **牢固**：关节囊
一句话：**关节既灵活又牢固，这两件事是分工的。**

**收口（1 分钟）**
肌肉只能拉不能推 → 一组收缩一组舒张 → 骨绕关节转 → 才有动作。

**分层建议**
- 基础班：只走 ①②④，记住「屈肘肱二头肌收缩」
- 较好的班：补 ③ 的「肌肉只能拉」这个前提，它解释了为什么必须两组

**快捷键**：1/2/3 切模式 · L 标注 · F 全屏

## 这一页怎么讲：尿的形成与排出

**① 先认路（3 分钟）**
第 1 步。四个器官一条通路：**肾造尿、输尿管送尿、膀胱存尿、尿道排尿。**
顺手纠正一个概念：**排便是「排遗」，不是「排泄」**——排泄排的是代谢废物（尿、汗、呼出的二氧化碳和水）。

**② 肾单位（5 分钟）**
第 2 步。一个肾单位就三样：**肾小球 + 肾小囊 + 肾小管**。
看清包与被包：**肾小球是一团毛细血管，被肾小囊包在里面**，肾小囊向下延伸成肾小管。
补一句：**集合管不是肾单位的一部分。**

**③ 滤过（6 分钟）—— 两个「筛」之一**
第 3 步。血液流经肾小球被筛一遍：**除血细胞和大分子蛋白质外**，水、无机盐、葡萄糖、尿素都滤到肾小囊，形成**原尿**。
一天生成约 **150 升**原尿——这个数字学生一般没概念，正好用来推下一步。

**④ 重吸收（6 分钟）—— 本页最值钱的一屏**
第 4 步。原尿流经肾小管，**全部葡萄糖、大部分水、部分无机盐**被捡回血液。
150 升 → 1.5 升，99% 的水被收回。
关键配对，务必钉死：**尿里有葡萄糖 → 肾小管坏；尿里有蛋白质 → 肾小球坏。**

**⑤ 排出与成分表（5 分钟）**
第 5 步。四行表：血细胞与蛋白质、葡萄糖、水、尿素。
让学生用这张表反推 ④ 里的两个判断——**如果尿里出现葡萄糖，是表里哪一行对不上？**

**收口（1 分钟）**
两句话：**肾小球滤过造原尿，肾小管重吸收变尿液；前者挡大个的，后者捡有用的。**

**分层建议**
- 基础班：只走 ①③④，记住「滤过造原尿、重吸收变尿」
- 较好的班：补 ⑤ 的推理题，以及「每天 150 升原尿为什么不吓人」

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–5 跳步 · L 标注 · F 全屏

## 这一页怎么讲：光合作用与呼吸作用

**① 光合作用（6 分钟）**
第 1 步。给一条式子：**二氧化碳 + 水 —(光能·叶绿体)→ 有机物 + 氧。**
跟着三种颜色的粒子走：二氧化碳从气孔进、水从导管来、氧气从气孔出，最后都汇到叶绿体。
一句话钉死：**光合是把光能变成化学能、存进有机物——它是「存」能量。**

**② 呼吸作用（6 分钟）**
第 2 步。方向全部反过来：**氧气从气孔进、二氧化碳从气孔出**，有机物从叶绿体送到线粒体。
一句话钉死：**呼吸是把有机物分解、把能量放出来——它是「花」能量。**

**③ 白天：两个都在跑（4 分钟）—— 本页最值钱的一屏**
第 3 步。先问：**「白天植物只光合、不呼吸，对不对？」**
几乎全班都会说对。然后指画面：**两个过程同时在跑**，只是光合比呼吸强，所以净结果是吸二氧化碳、放氧气。

**④ 夜里：只有呼吸（3 分钟）**
第 4 步。没有光，叶绿体停工，线粒体照常上班。
顺势问：**「那卧室里能摆很多绿植吗？」**——夜里它们和你抢氧气。

**⑤ 一张表（4 分钟）**
第 5 步。四行：场所、条件、原料、产物。
不要按行背，按「场所 → 条件 → 原料 → 产物」走一遍，再倒着走一遍。
最后补范围：**光合只在含叶绿体的细胞，呼吸在所有活细胞。**

**收口（1 分钟）**
两句话：**光合储存能量，呼吸释放能量；光合只在有光时进行，呼吸昼夜不停。**

**分层建议**
- 基础班：只走 ①③⑤，记住「白天不是只光合」
- 较好的班：补 ② 的「有机物从叶绿体运到线粒体」，以及呼吸作用释放的能量去了哪里

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–5 跳步 · L 标注 · F 全屏

## 这一页怎么讲：水的利用与散失

**① 一滴水的旅程（3 分钟）**
第 1 步，跟着蓝色小球走一遍：**土壤 → 根毛 → 根 → 茎 → 叶脉 → 气孔 → 空气。**
先给一个反常识的数字：根吸上来的水，**约 99% 都从气孔散掉了**，只有一小部分留在体内。

**② 根毛（3 分钟）**
第 2 步。**根毛是根尖表皮细胞向外伸出的一根细突起**，不是根的分支。
问一句：**「为什么要长这么多？」**——表面积越大，吸水越快。
顺势解释：移栽植物伤了根毛，植物就萎蔫，原因就在这里。

**③ 导管（5 分钟）—— 本页最值钱的一屏**
第 3 步。这里必须把两套管道分开讲：

| 管道 | 位置 | 运什么 | 方向 |
|---|---|---|---|
| **导管** | 木质部 | **水和无机盐** | **向上** |
| **筛管** | 韧皮部 | 有机物 | 向下 |

一句话钉死：**导管运水，筛管运糖。** 这是七下最常互换的一对概念。

**④ 气孔（4 分钟）**
第 4 步。**气孔是两个保卫细胞围成的空隙**——不是细胞，是空隙。
保卫细胞吸水膨胀 → 气孔张开；失水收缩 → 气孔关闭。所以植物能自己决定什么时候「放水」。
补一句：**气孔既是蒸腾的门，也是气体交换的门**，同一扇门干两件事。

**⑤ 蒸腾作用的意义（4 分钟）**
第 5 步。**不是浪费水。** 三件事：
1. 产生**蒸腾拉力**，把水和无机盐从根拉到几十米高的树顶
2. **降低叶片温度**，夏天不至于被晒伤
3. 把水送回大气，参与**生物圈的水循环**

收口因果链：**蒸腾失水 → 产生拉力 → 水和无机盐被拉上来。** 没有蒸腾，根吸的水上不去。

**分层建议**
- 基础班：只走 ①③④，记住「导管运水、气孔是门」
- 较好的班：补 ⑤ 的因果链，以及「为什么大树移栽要剪掉部分枝叶」

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–5 跳步 · L 标注 · F 全屏

## 这一页怎么讲：心脏与血液循环

**① 四个腔（4 分钟）**
停在第 1 步，先给一个定位：**「心脏是一台双泵——右半边送血去肺，左半边送血去全身。」**
让学生点四个腔，每次只问一句：**「它收谁的血，又泵到哪儿去？」**
补一句：中间那道隔板把左右两半完全分开，**两边的血不会直接混**。

**② 肺循环（4 分钟）**
点第 2 步，跟着白色小球走一遍：**右心室 → 肺动脉 → 肺 → 肺静脉 → 左心房。**
这里一定要停一下，指着回来的红管子问：**「这条叫肺静脉，里面的血是动脉血还是静脉血？」**
学生几乎都会答「静脉血」。答案相反——**肺静脉里是动脉血**。这是本节第一大坑，就在这里钉死。

**③ 体循环（4 分钟）**
点第 3 步：**左心室 → 主动脉 → 全身组织 → 上、下腔静脉 → 右心房。**
追问：**「四个腔里，哪个壁最厚？为什么？」**
看图上左心室那圈特别粗的边——**它要把血送到全身，路最长，所以壁最厚。**

**④ 两条循环接力（3 分钟）**
点第 4 步，四条路同时流。让学生在图上找两个接点：右心室接肺循环、左心室接体循环。
口诀：**室出发、房回来。**

**⑤ 血在哪变色（3 分钟）**
点第 5 步，只问一句：**「全身有几个地方能让血变色？」**
两处：**肺**（静脉血→动脉血）、**全身组织**（动脉血→静脉血）。
收口：**判断动脉血还是静脉血，只看含氧量，不看血管叫什么名字。**

**分层建议**
- 基础班：只走 ①②③⑤，记住「右室出、左房回」
- 较好的班：补「瓣膜为什么能让血不倒流」，以及「为什么左心室壁最厚」

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–5 跳步 · L 标注 · F 全屏

## 这一页怎么讲：消化和吸收

**① 全程认路（3 分钟）**
第 1 步，跟着小球走一遍：**口腔 → 食道 → 胃 → 小肠 → 大肠 → 肛门。**
只强调一件事：**这是一条单向的管道**，食物只能往前走。

**② 口腔（3 分钟）**
第 2 步。先问：**「馒头越嚼越甜，甜味哪来的？」**
不是本来就甜——是**唾液把淀粉分解成了麦芽糖**。
钉一句：**淀粉的消化从口腔就开始了。**

**③ 胃（4 分钟）**
第 3 步。这里有本节第一个反差：**淀粉到了胃里反而停了。**为什么？胃液是强酸的，唾液淀粉酶在这里失活。
胃只干一件事：**开始消化蛋白质**。

**④ 小肠（5 分钟）—— 本页最值钱的一屏**
第 4 步。三种消化液在这里汇合：**胆汁、胰液、肠液**。
重点盯胆汁：**它不含消化酶**，只把脂肪切成小滴（物理性消化）。
一句话收口：**胆汁负责「切小」，胰液和肠液负责「拆开」。**

**⑤ 吸收（3 分钟）**
第 5 步。**小肠绒毛把吸收面积放大到约 200 平方米。**
大肠只吸水——**不是吸收养分的主要场所。**
收口：**消化主要在小肠，吸收也主要在小肠。**

**分层建议**
- 基础班：只走 ①②④⑤，记住「胆汁不含消化酶」
- 较好的班：补「为什么小肠是主战场」（长度、面积、消化液三件事）

**快捷键**：空格暂停流动 · ←→ 切步骤 · 1–5 跳步 · L 标注 · F 全屏

## 这一页怎么讲：肺泡与气体交换

**① 先给结论（2 分钟）**
先不点任何结构，只问：**「氧气是怎么从肺里跑到血液里的？是肺把它「吸」进去的吗？」**
多数学生会说是。先不揭晓。

**② 两层壁（4 分钟）**
点「两层壁」。气体要过的墙只有两堵：**肺泡壁、毛细血管壁，各只有一层细胞。**
这是本节最常考的一句原话，要让学生看着图说一遍。

**③ 氧气方向（4 分钟）**
点「氧气方向」。**肺泡里氧多、血液里氧少，所以氧气自己往血液里走。**
回到开头那个问题：**肺没有把氧气「抽」进血液**，它只负责让空气进出。真正让氧气过去的是**浓度差（扩散）**。

**④ 二氧化碳方向（3 分钟）**
点「二氧化碳方向」。方向正好相反：**血液里二氧化碳多，肺泡里少，所以往肺泡里走。**
强调：**两个方向同时发生**，不是「先吸氧再排二氧化碳」。

**收口（1 分钟）**
一句话：**气体从多的地方往少的地方走；肺泡和毛细血管都只有一层细胞，所以走起来毫不费力。**

**分层建议**
- 基础班：只走 ②③，记住「两层壁各一层细胞」+「氧多往氧少走」
- 较好的班：补「为什么肺泡数量多、总面积大」，以及吸气时胸廓与气压的关系

**快捷键**：1/2/3 切模式 · L 标注 · F 全屏

## 加一个新模型

**三步，不用写图形代码。**

**第 1 步：准备内容数据**

复制 `_src/data/生物/bio-7a-1.2.2-01.json`，改名为新模型 id，例如 `bio-7a-1.2.1-01.json`，然后改里面的：
- `hero` —— 标题、本页目标句、操作提示
- `parts` —— 每个结构 / 知识点的「是什么 / 作用 / 易错点」
- `labels` —— 标注文字与引线坐标
- `shapes` —— 图形（矩形 / 椭圆 / 圆 / 路径 / 文字）的坐标与颜色

**第 2 步：在 `catalog.json` 登记**

在 `models` 数组里加一条，填好 `id / grade / section / title / file / template / duration / curriculum`。

**第 3 步：构建 + 校验**

```bash
python _src/tools/build.py
python _src/tools/check.py
```

`build.py` 会把模板和内容拼成一个单文件 HTML，同时重建 `index.html`。
`check.py` 会查 8 项，任何一项不过都会报出来，**过了再拿去上课**。

> 只改文案？改 `_src/data/` 里的 JSON 然后重跑 build 就行，完全不碰图形代码。
