## 一、先说结论

**八下共 13 节，值得建模的是 9 个：必做 5 个、可选 4 个。**

八下是全四册里**抽象度最高的一册**，前面三册的难点都还能"画出来"，八下的核心对象（基因、比率、代际概率）本质上不可见：

| 册 | 主要难点 | 典型 |
|---|---|---|
| 七上 | **看不见** | 细胞、染色体、微生物 |
| 七下 | **进不去**（在身体里） | 血液循环、消化、气体交换 |
| 八上 | **看不见 + 要推理** | 神经冲动、免疫过程、能量流动 |
| **八下** | **没有实体**（是规律） | 基因的传递、3:1 的比率、生男生女各半 |

## 四、已交付模型说明

### 1. 有性生殖（6.1.2）　★★　✅ 已完成

**为什么必须做**
这一节的考点几乎全在**两条对应关系**上：`子房壁 → 果皮`、`胚珠 → 种子`。
学生的错法很固定——把「整个果实」说成由胚珠发育而来（因为种子最显眼）。
而这条对应关系讲不清，是因为**花和果实在图上从来不同屏**：课本上一张花的图、一张果实的图，中间那段"谁变成谁"全靠想象。

**页面里要有什么**
左边一朵花的剖面（柱头、花柱、子房、胚珠、花药、花丝），右边一个果实剖面，
中间一条「发育」箭头。**关键是让两边同屏。**

**核心设计：颜色即来源**
- 子房壁与果皮**同一种粉**，胚珠与种子**同一种棕**。
- 学生不用读文字，看「粉色的变成粉色、棕色的变成棕色」就完成了配对。
- 配套约束：**子房里画 2 个胚珠，果实里就必须画 2 粒种子**——
  数量不一致会直接毁掉「一个胚珠成一粒种子」这条结论（第一版画了 3 粒，已改）。

**必须讲透的三句话**
1. **精子不能自己移动**，靠花粉管送进胚珠——所以"传粉"和"受精"是两件事。
2. **子房壁 → 果皮，胚珠 → 种子**——果实来自整个子房，不是来自胚珠。
3. **有性生殖的后代具有两个亲本的遗传特性**，变异更丰富，适应力更强。

**易错点**：把果实说成由胚珠发育；把花粉当精子；把传粉与受精混为一件事。

### 2. 基因在亲子代间的传递（6.2.2）　★★★　✅ 已完成

**为什么必须做**
这一节是整章的地基：**不讲清「生殖细胞里染色体减半」，后面讲显隐性、性别决定全是空中楼阁**。
而它恰好是"看不见"的典型——染色体在显微镜下能看，但"每对只走一条"这件事只在分裂的一瞬间发生。

学生最典型的错法有两个：
- 认为**受精卵的染色体数是父母之和**（46 + 46 = 92）；
- 认为**亲代把性状直接传给孩子**（"我爸爸双眼皮所以我双眼皮"）。

**页面里要有什么**
三段横向路径，父方在上、母方在下，汇到右端受精卵：

```
父方体细胞（2 对，蓝）──→ 精子（2 条）──┐
                                        ├──→ 受精卵（2 对，蓝 + 红）──→ 子代
母方体细胞（2 对，红）──→ 卵细胞（2 条）─┘
```

**颜色即来源**：蓝 = 来自父方，红 = 来自母方。受精卵里一对同源染色体必然一蓝一红，
这是"一半一半"最直接的证据，不用文字解释。

**必须讲透的三句话**
1. **体细胞里染色体成对，基因也成对**——一条来自父方、一条来自母方。
2. **形成生殖细胞时，每对只走一条**——所以染色体减半，基因也减半（成单）。
3. **受精后恢复成对**——受精卵的染色体数与体细胞**相同**，不是相加。

**易错点**：把受精卵的染色体数算成 92 条；认为精子中的染色体也成对；
认为父母直接传递性状（实际传的是基因，性状在子代身上重新表达）。

### 3. 基因的显性与隐性（6.2.3）　★★★　✅ 已完成

**为什么必须做**
这节有两个「学生自以为懂」的地方：
- **子一代全是高茎** → 学生断定「矮茎基因没了」，于是无法解释子二代为什么又出现矮茎；
- **基因组成 1 : 2 : 1 与表现 3 : 1** → 两个比反复混用，是遗传题失分最多的一处。

两处都不是记忆问题，是**看不见代际**造成的。必须让两代同屏。

**页面里要有什么**
按课本遗传图解的纵向顺序，四层同屏：

```
亲代    纯种高茎 DD    ×    纯种矮茎 dd
              ↓                 ↓
生殖细胞      D                 d
              ↓                 ↓
子一代              Dd（高茎）        ← 矮茎"消失"在这里
                    ↓ ↓ ↓ ↓
子二代   DD高  Dd高  Dd高  dd矮     ← 又回来了
```

**颜色直接编码表现**：高茎一律绿框、矮茎一律黄框。
子二代那一排**三绿一黄**，3 : 1 不用数就看得出来。

**必须讲透的三句话**
1. **隐性基因不会消失，只是被显性基因盖住了表现**——所以子二代能"重现"矮茎。
2. **有 D 就是高茎，两个都是 d 才矮**——DD、Dd 同表现，dd 才不同。
3. **基因组成 1 : 2 : 1，性状表现 3 : 1**——问的是哪个，答案就是哪个比。

**易错点**：认为子一代没有矮茎基因；把 1 : 2 : 1 当成表现比例；认为显性基因"更强大"或更容易遗传。

### 4. 人的性别决定（6.2.4）　★★★　✅ 已完成

**为什么必须做**
「生男生女由父亲决定」这句话学生背得出，但**说不清为什么**，于是「第一胎女孩、第二胎更容易生男孩」这个错误观念清不掉。
根因是：学生把父母的贡献看成对等的（各给一半），实际上**母亲这一侧根本没有变量**。

**页面里要有什么**
和 6.2.2 共用一套视觉语言（蓝 = 来自父亲、红 = 来自母亲、长棒 = X、短棒 = Y）：

```
母亲 XX ──→ 卵细胞（只含 X）─┐
                              ├─→ XX 女孩 / XY 男孩
父亲 XY ──→ 精子（X 或 Y）──┘
```

**必须讲透的三句话**
1. **女性的性染色体是 XX，男性是 XY**——差别只在第 23 对，前 22 对完全一样。
2. **卵细胞只能含 X，精子含 X 或含 Y**——变量在父亲这里。
3. **性别由父亲给的是 X 还是 Y 决定，机会各半，且每次独立。**

**易错点**：认为生男生女由母亲决定；认为卵细胞可能含 Y；认为「第一胎女孩第二胎更容易生男孩」。

### 5. 生物进化的原因（6.3.3）　★★★　✅ 已完成

**为什么必须做**
这节最容易被讲成拉马克：**「长颈鹿为了吃到高处的叶子，努力把脖子伸长」**。
一旦这么讲，学生记住的是「生物为了适应而主动改变」——正好和自然选择相反。
根因不在学生，而在图：**课本插图通常只画「谁活下来了」，没画「谁本来就在、谁被筛掉」。**

**页面里要有什么**
左右两棵同一棵树的两个时代，**保护色直接用颜色表达**：

```
1850 年 浅色树干          1950 年 深色树干
  4 浅蛾（几乎看不见）       1 浅蛾（红圈标出，极其扎眼）
  2 深蛾（一目了然）         5 深蛾（融进树皮）
        ↘       工厂/煤烟        ↙
          深色蛾比例 33% → 83%
```

**关键设计**
1. **蛾的颜色就是环境的颜色**：浅蛾画在浅树干上、深蛾画在深树干上，都调到「轮廓可辨但几乎融入」，
   不用文字解释保护色，看一眼就懂（第一版深蛾描边太亮，反而比树皮显眼，已改）。
2. **左右两栏的蛾数量必须和底部比例条对得上**：左 2/6 = 33%，右 5/6 = 83%。
3. **第 3 步用红圈只标那只浅蛾**，其余五只深蛾"隐身"——一屏之内就能读出「谁显眼谁倒霉」。

**必须讲透的三句话**
1. **变异本来就存在，与环境无关**——深色蛾不是"为了适应"才变深的。
2. **变的是环境，不是蛾**——树被熏黑，蛾一只都没变。
3. **个体不变，群体在变**——进化说的是群体比例的改变。

**易错点**：认为生物能"为了适应"而主动变异；认为环境能"让"生物产生需要的变异；
把进化理解成某个个体发生变化；认为深色蛾是"新进化出来的类型"。
