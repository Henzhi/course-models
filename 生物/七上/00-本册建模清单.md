## 四、逐个说明

### 1. 学习使用显微镜（1.2.1）　★★★　✅ 已完成

**为什么必须做**
学生第一次接触精密仪器，光路完全不可见；放大倍数、物像移动、视野亮度三件事都反直觉。这是七上第一个实验课，也是第一个"听不懂就再也跟不上"的坎。

**页面里要有什么**

| 视图 | 内容 | 关键交互 |
|---|---|---|
| ① 结构 | 显微镜剖面，标出目镜、物镜、粗/细准焦螺旋、反光镜、遮光器、通光孔、载物台 | 点击任一部件看作用 |
| ② 对光 | 三步：转低倍物镜 → 对准通光孔 → 反光镜对光 | 拖「光圈大小」和「反光镜（平面/凹面）」→ 视野亮度实时变 |
| ③ 调焦成像 | 镜筒下降 → 看物镜；镜筒上升 → 看目镜 | 拖粗准焦螺旋，物像由模糊到清晰 |
| ④ 放大倍数 | 同一标本在 10× / 40× 下的视野 | 滑块切换 → 细胞变大、数量变少、视野变暗 |
| ⑤ 物像移动 | 玻片向左移，物像向右移 | 拖玻片，物像反向移动（**本页最值钱的一屏**） |

**必须讲透的四句话**
1. 放大倍数 = 目镜 × 物镜（**不是相加**）
2. 物像移动方向和玻片移动方向**相反**
3. 先低倍、后高倍；换高倍后只能动细准焦螺旋
4. 下降镜筒时眼睛看**物镜**，上升时看**目镜**

**可加的小练习**：视野里出现一个污点，分别转动目镜、移动玻片、换物镜，看污点动不动 → 判断污点在哪。
这个练习在高倍镜下最容易考，且用交互做出来比讲三遍有效。

**难点 / 风险**：手写光路容易画歪（透镜折射、光线汇聚）。**先写 probe 验证页**，把成像位置算对再写正式页。

### 2. 细胞的生活（1.2.4）　★★★　✅ 已完成

**为什么必须做**
三件事都不可见：物质怎么进出细胞、能量怎么转换、细胞核为什么是控制中心。

**页面里要有什么**

- **视图①「物质进出」**：细胞膜做选择透过——有用的物质（氧气、水、葡萄糖）进入，废物（二氧化碳）排出，有害物质被挡住。用粒子动画表现"能过 / 不能过"。
- **视图②「能量转换」**：两个车间并排
  - 叶绿体：光能 → 化学能（**只有植物绿色部分有**）
  - 线粒体：化学能 → 细胞能用的能量（**动植物都有**）
- **视图③「细胞核是控制中心」**：细胞核控制着细胞的生长、发育和繁殖。
  可用克隆羊多莉作实例——去核卵细胞 + 提供细胞核的羊 → 多莉长得像谁？

**必须讲透的三句话**
1. 细胞膜**控制物质进出**，细胞壁不能（它是全透的）
2. 叶绿体是"存钱"，线粒体是"花钱"——一个储存能量，一个释放能量
3. 遗传信息在**细胞核**里，所以多莉像提供细胞核的那只羊

**易错点**：把"细胞膜控制物质进出"答成"细胞壁"；认为动物细胞没有线粒体。

### 3. 细胞通过分裂产生新细胞（1.3.1）　★★★　✅ 已完成

**为什么必须做**
过程不可见，染色体数目变化抽象，"数染色体"是全册最高频的错误之一。

**页面里要有什么**
五阶段动画：分裂前 → 染色体复制 → 排列到中央 → 染色体分离 → 形成两个新细胞。
支持 2 条 / 4 条染色体切换，单步 / 连播，每阶段配解说与观察提示。

**必须讲透的三句话**
1. 复制之后，**染色体数目不变**（一条变两条"姐妹"，仍由一个连接点连住）
2. **数染色体要数连接点（着丝粒）**，不是数"棍子"
3. 新细胞和原细胞的染色体数目**相同**（不是减半）

**说明**：旧版有 4 个页面做过这个知识点（已归档在 `_archive/`），动画逻辑可参考，但要按新底座（模板 + 数据 JSON）重写。

### 4. 动物体 / 植物体的结构层次（1.3.2 + 1.3.3）　★★　✅ 已完成

**为什么合并**
两节讲的是同一件东西的两条路径，分开做会让"植物没有系统"这个关键差异被割裂。合成一页，对比着看。

**页面里要有什么**
一条**缩放链**，从细胞一路放大到个体：

- 动物：细胞 → 组织 → 器官 → 系统 → 个体（五个台阶）
- 植物：细胞 → 组织 → 器官 → 植物体（**四个台阶，没有系统**）

可逐级停靠，每级显示该层的例子（如"血液是组织""叶是器官"）。

**必须讲透的三句话**
1. 植物**没有系统**这一层
2. 血液是**组织**，不是器官；皮肤是**器官**
3. 叶是**器官**（由多种组织构成），不是组织

**难点**：层级缩放要让人看清"下一层是上一层的一部分"，不是并排罗列。画面上要有包含关系（放大镜 / 嵌套框）。

### 5. 单细胞生物（1.3.4）　★★　✅ 已完成

**为什么必须做**
"一个细胞就能完成全部生命活动"非常反直觉，而草履虫的结构在课本上是一张平面图，学生记不住谁干什么。

**页面里要有什么**
草履虫剖面，点击标注：纤毛、表膜、口沟、食物泡、胞肛、收集管与伸缩泡、大核、小核。
右侧同步一张"七大生命活动对照表"：运动 / 呼吸 / 摄食 / 消化 / 排泄 / 生殖 / 应激性，每项对应哪个结构。

**必须讲透的三句话**
1. 草履虫是**单细胞动物**，一个细胞就是整个身体
2. **伸缩泡排废物**，食物泡负责消化——两个"泡"别混
3. 它能对外界刺激做出反应（应激性），说明单细胞生物也是"活的"

**易错点**：把草履虫当成植物（它是动物）；把伸缩泡当成消化结构。

### 6. 细菌 / 真菌 / 病毒（2.3.2–2.3.4）　★★　✅ 已完成

**为什么合并**
三节的核心是同一个问题：**它们有没有细胞结构、有没有细胞核**。分三页做，学生记不住差别；并排放，差异一眼就看出来。

**页面里要有什么**
三栏并排：细菌 / 真菌 / 病毒，点击结构看详解，底部一张对比表：

| | 细菌 | 真菌 | 病毒 |
|---|---|---|---|
| 细胞结构 | 有（单细胞） | 有 | **无** |
| 成形的细胞核 | **无**（只有 DNA 集中区） | 有 | 无 |
| 细胞壁 | 有 | 有 | 无 |
| 营养方式 | 多数异养 | 异养 | **寄生** |
| 繁殖 | 分裂 | 孢子 | 在活细胞内复制 |

**必须讲透的三句话**
1. 细菌**没有成形的细胞核**，只有 DNA 集中的区域
2. 真菌**有细胞核**，所以它和细菌不是一类
3. 病毒**没有细胞结构**，只能寄生在活细胞里

**易错点**：芽孢不是生殖细胞，是细菌的休眠体；病毒不能用培养基培养。

**可复用性**：这一页的画法和"植物细胞 vs 动物细胞"完全同构（多栏对比 + 点击标注 + 对比表），T1 模板可以直接套。

---

### 7. 种子植物：菜豆与玉米种子结构（2.1.2）　★ 可选

**为什么值得做**：种子内部结构看不见，单/双子叶与"胚的组成"是高频错。
**页面**：两个种子剖面并排，标胚芽、胚轴、胚根、子叶、胚乳、种皮。
**讲透**：玉米是单子叶（1 片子叶 + 胚乳），菜豆是双子叶（2 片子叶，无胚乳）；**胚 = 胚芽 + 胚轴 + 胚根 + 子叶**。
**不做也不影响**：这节有分组实验（泡软的种子解剖），实物比屏幕更有效。若课时紧，优先保实验。

---

### 8. 藻类、苔藓、蕨类（2.1.1）　★ 可选

**只做一页，不做三页**：三类对比 + 孢子生殖。核心是"从水生到陆生的过渡"这条线索。
**风险**：容易做成三张"特征罗列"的图，那就退化成课本搬运。如果做不出"为什么苔藓长不高、蕨类有了输导组织"这条因果，就不做。

---

### 9. 脊椎动物（2.2.2）　★ 可选

**只挑三个真难点**，不做类群罗列：
- 鱼的鳃：水流方向与血液方向相反（逆流交换），所以能高效提氧
- 两栖动物的变态发育：蝌蚪（鳃、尾）→ 成蛙（肺、四肢）
- 鸟的双重呼吸：吸气、呼气都能进行气体交换

**其余内容**（各类群代表动物、体表、体温）属于记忆型，用表格和抽背解决。

## 八、口径说明

- **章节位置**：依据人教版 2024 年秋启用的七上目录核对（第一单元三章、第二单元四章）。
- **课标层次**：本清单中的"必做 / 可选"是**教学判断**，不是课标原文的层级。
  页面里标注的课标层次沿用三档：**了解 / 理解 / 应用**。
- **课标条目号**：未核实到具体条目的，一律不标条目号，只写层次——**不臆造**。
- **超纲内容不进七上**：DNA 双螺旋、核小体、组蛋白、细胞器超微结构等属于高中或更专业的表述，
